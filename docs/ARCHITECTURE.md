# Архитектура

## app/

App Router.

Все страницы находятся здесь.

---

## components/

Переиспользуемые UI-компоненты.

---

## lib/

Слой бизнес-логики.

Любая работа с Prisma должна происходить здесь.

Например:

- projects.ts
- profiles.ts
- follows.ts
- storage.ts

Не писать Prisma напрямую в React-компонентах.

---

## prisma/

Схема и миграции.

---

## API

Все серверные изменения происходят через Route Handlers.

Компоненты не должны обращаться к Prisma напрямую.

---

## Авторизация

Используется Auth.js v5.

Проверка пользователя всегда происходит на сервере.
