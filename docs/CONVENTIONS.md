# Правила проекта

## Не делать

- не переписывать архитектуру
- не создавать новые абстракции без необходимости
- не дублировать код
- не создавать вторую реализацию существующей функции

---

## Делать

- переиспользовать существующие компоненты
- использовать существующие стили
- использовать существующие helper-функции
- писать production-ready код
- соблюдать существующий стиль проекта

---

## Перед изменениями

Если архитектуру необходимо изменить:

1. объяснить почему;
2. перечислить плюсы;
3. перечислить минусы;
4. предложить альтернативу.
