# BARNI

## Что такое BARNI

BARNI — социальная платформа для творческих людей со всего мира.

Пользователи могут:

- создавать профили;
- публиковать проекты;
- оформлять свои страницы;
- взаимодействовать между собой;
- находить других участников сообщества.

Главная цель проекта — создать красивую, современную и удобную платформу для публикации творческих работ.

---

## Стек

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Prisma ORM
- PostgreSQL
- Auth.js v5
- Discord OAuth
- Discord Bot API
- Supabase Storage

---

## Основные принципы

- production quality
- не ломать архитектуру
- минимальные изменения существующего кода
- максимально переиспользовать существующие компоненты
- не создавать дублирование
- использовать существующие lib/*
- Prisma — единственный источник работы с БД
- API через Route Handlers
